# Collaborator Stage 2 — `CONTEXT.md` And Exit

## What `CONTEXT.md` Must Capture

Under `## Check List`, paste the current contents of `CHECKLIST.md` from the active stage and keep the checkboxes current there.

At minimum, record:

- current stage and handoff status
- collaborator machine identity
- important runtime paths
- whether task-ready data is fully staged on the collaborator machine
- software and runtime assumptions
- what changed this session
- exact testing state
- access-grant and migration notes

Do not store transient IPs in persistent task docs.

---

## Exit Criteria

Stage 2 is complete only when:

- the implementation matches `TASK_INTAKE.md`
- the run script is verified
- the staged task data exists on the collaborator machine
- positive and negative tests behave correctly
- `README.md` and `REPRO_COMMANDS.md` are current
- `CONTEXT.md` is current
- the task is ready for admin migration handoff
