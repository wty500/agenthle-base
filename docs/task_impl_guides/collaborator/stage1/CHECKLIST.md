# Stage 1 Checklist

Copy this checklist into `CONTEXT.md` under `## Check List` while the task is in Stage 1, and keep it updated in place.

- [ ] Collaborator Stage 1 guide read
- [ ] Real source data located and documented
- [ ] Working collaborator VM or workstation chosen, access verified, and staging path decided
- [ ] Stage 1 docs scaffolded (`DATA_INTAKE.md`, `TASK_INTAKE.md`, `scripts/DATA_PIPELINE.md`, `PITFALLS.md`, `CONTEXT.md`)
- [ ] Raw data inspected and mapped to task-ready assets
- [ ] Raw data processed or staged per `scripts/DATA_PIPELINE.md`
- [ ] Canonical runtime layout decided for `input/`, `reference/`, `output_test_pos/`, `output_test_neg/`, and `software/`
- [ ] Software provisioning plan decided, including any admin handoff items
- [ ] Stage 1 planning review loop run, with stable takeaways captured in `CONTEXT.md` and `PITFALLS.md`
- [ ] Stage 1 docs updated based on confirmed review feedback
- [ ] Stage 1 planning stable
